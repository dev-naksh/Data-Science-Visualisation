# Data Science & Visualization Portfolio

Welcome to my central repository for data science and data visualization projects. This repository showcases end-to-end analytical workflows, ranging from exploratory data analysis (EDA) and statistical modeling to machine learning implementation and advanced visual storytelling.

## 🛠️ Tech Stack & Libraries

### 🧠 Data Science & Machine Learning
*   **Data Manipulation:** `Pandas`, `NumPy`, `Polars` — efficient data ingestion, cleaning, and preprocessing.
*   **Machine Learning & Stats:** `Scikit-Learn`, `Statsmodels`, `XGBoost` — regression, classification, clustering, and predictive modeling.
*   **Deep Learning:** `TensorFlow` / `PyTorch` — neural network architectures and deep learning applications.

### 📊 Data Visualization & Business Intelligence
*   **Static Plotting:** `Matplotlib`, `Seaborn` — publication-quality statistical graphics and exploratory charts.
*   **Interactive Graphics:** `Plotly`, `Bokeh` — dynamic, zoomable charts and web-ready visualizations.
*   **Dashboards & Web Apps:** `Streamlit`, `Dash` — deploying machine learning models and analytical findings into interactive web applications.
*   **Geospatial Analysis:** `Geopandas`, `Folium` — mapping and spatial data visualization.
